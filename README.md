## 🌟 نظرة عامة | Overview

**Mkwhats** هي منصة سحابية متقدمة متعددة المستأجرين (**Multi-Tenant WhatsApp CRM & AI Automation SaaS**) مصممة لتمكين الشركات، المتاجر الإلكترونية، العيادات، وفرق المبيعات من إدارة وتنمية أعمالهم عبر واتساب بأعلى كفاءة وأمان.

تجمع المنصة بين **قوة الذكاء الاصطناعي**، **بوابة الربط المزدوج بالواتساب**، و**إدارة الحملات والمبيعات** في واجهة موحدة فائقة السرعة تدعم اللغتين العربية والإنجليزية.

## ⚡ تقنيات المنصة | Tech Stack

- **Frontend / Backend**: Next.js 16 (App Router, Server Actions, API Routes), React 19, TypeScript.
- **Styling**: Tailwind CSS v4, Lucide Icons, Modern Glassmorphism & Dark/Light Themes.
- **Database & Storage**: Supabase (PostgreSQL, Row Level Security, pgvector, Realtime, Storage).
- **AI Engines**: Google Gemini 2.0 Flash, OpenAI GPT-4o, Whisper STT.
- **WhatsApp APIs**: Official Meta Cloud API + Evolution API (Self-hosted QR Code Gateway).
- **Internationalization**: Full Bilingual support (Arabic 🇸🇦 & English 🇬🇧) via `next-intl`.

## 🛠️ التشغيل والبدء السريع | Getting Started

### 1. استنساخ المشروع وتثبيت الحزم:
```bash
git clone https://github.com/mstotv/Mkwhats.git
cd Mkwhats
npm install
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف المتغيرات البيئية وقم بتعبئة مفاتيح Supabase ومفاتيح الواتساب:
```bash
cp .env.local.example .env.local
```

### 3. تشغيل بيئة التطوير المحلية:
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

## 🛡️ الأمان والخصوصية | Security & Multi-Tenancy

- **عزل بيانات كامل (Multi-Tenancy)**: كل حساب معزول تماماً ومحمي بواسطة سياسات Row Level Security (RLS) الصارمة في PostgreSQL.
- **تشفير المفاتيح**: تشفير مفاتيح الربط والرموز الحساسة باستخدام تشفير `AES-256-GCM`.
- **حماية Webhook**: التحقق الأمني من تواقيع HMAC لكافة أحداث الواتساب والمتاجر الإلكترونية.
